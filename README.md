CCP Games is the Reykjavik-based studio behind EVE Online, the long-running single-shard massively multiplayer space sandbox. CCP operates one of the most mature third-party developer programs in gaming through the EVE Swagger Interface (ESI) - a public, versioned REST API that exposes character, corporation, alliance, market, industry, universe, and fleet data from the live Tranquility server. ESI is secured with EVE SSO (OAuth 2.0 / OpenID Connect on login.eveonline.com) using fine-grained per-scope consent, and is governed by a free third-party Developer License Agreement. This profile enriches the CCP Games entry with the real ESI API surface: its OpenAPI 3.1 description, authentication and OAuth scope model, error and error-limit conventions, lifecycle/deprecation posture, and agent-readiness artifacts.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for CCP Games: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
